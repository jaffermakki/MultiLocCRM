{% include "_csrf.html" %}

Use {shop_name} to insert your shop name.

SMTP required .env variables:
SMTP_HOST — e.g. smtp.gmail.com, smtp.office365.com
SMTP_PORT — 587 (STARTTLS, default) or 465 (SSL)
SMTP_USER — your email login username
SMTP_PASSWORD — your email password or app password
SMTP_USE_SSL — optional, set to true for port 465
Gmail and Outlook usually require an "App Password", not your normal password.
SendGrid required .env variables:
SENDGRID_API_KEY — from SendGrid → Settings → API Keys
Your From Address above must be a verified Sender in SendGrid.
Mailgun required .env variables:
MAILGUN_API_KEY — from Mailgun → Settings → API Keys
MAILGUN_DOMAIN — your sending domain, e.g. mg.yourshop.com
MAILGUN_REGION — optional, us (default) or eu
Postmark required .env variables:
POSTMARK_SERVER_TOKEN — from Postmark → Servers → [your server] → API Tokens
Your From Address above must be a verified Sender Signature in Postmark.
Amazon SES required .env variables:
AWS_ACCESS_KEY_ID — IAM credentials with ses:SendEmail permission
AWS_SECRET_ACCESS_KEY
AWS_REGION — e.g. us-east-1
Also run: pip install boto3
Your From Address must be a verified SES identity.
